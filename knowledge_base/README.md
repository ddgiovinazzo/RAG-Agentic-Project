# 🧠 Knowledge Base Directory (LLM RAG Vector Store)

This directory contains enterprise knowledge base documents designed to be indexed into **AnythingLLM** / RAG Vector Store for the **AI Support Triage Agent**.

---

## 📥 Ingestion Instructions

1. Open **AnythingLLM UI** (`http://localhost:3001`).
2. Navigate to your active workspace (e.g. `my-workspace`).
3. Drag & drop the `.txt` / `.md` files from this `knowledge_base/` folder into AnythingLLM.
4. Click **Save and Embed** to index the documents into vector embeddings.
5. Test in the AI Assistant chat via prompt:  
   *"What is the home office equipment allowance policy?"* or *"How do I setup VPN on Mac?"*
